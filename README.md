# Проект "КотлOFF Service"

## Frontend
* Core
    * React 18+ 
    * React Router v6
* Интеграция
    * Яндекс MapKit API
    * Jivo API (чат поддержки)
    * Telegram Widget API
* Деплой 
    * Netlify (CI/CD)

## Backend 
* Framework
    * Nest.js- используется для создания архитектуры, структуры и порядка
    * Node.js - используется для создания фундамента и самой с реды для работы

* Базы данных
    * Firebase (Realtime Database / Firestore) - тут будет храниться вся кэшированная информация, получаемая от пользователей после заполнения формы на сайте
    * Google Sheets API (резервное хранение) - та же база данных, но она получает информацию не напрямую с сайта, а уже из Firebase, она не хэшированая и содержит базовый минимум инфомрации

* Безопасность 
    * Argon2 для хеширования
    * Персональные данные (ФЗ-152)
    * JWT аутентификация
Тут особо нечего описывать, и так все понятно :)

* Telegram Bot
    * Nest.js Telegraf/NestJS Telegram - суть описывалась ранее
    * Админ-панель в боте - необходима, чтобы один главный администратор мог управлять всеми участниками бота
    
* API
    * REST API - ситсема, необходимая для получения результата о совершенных действиях (отправляешь запрос на бд, а она возвращает ответ)
    * Webhooks - это, по сути, просто уведомления о событиях, например - уведомление от бота о поступлении заявки

## Telegram—Bot
При разработке сайта мы также создали двух Telegram-ботов, которые работают в связке для автоматического приёма и уведомления о заявках с сайта.

Боты:

@kotloffgazbot — основной бот-администратор (КотлOFF admin)

@kotloffgazsupportbot — вспомогательный бот поддержки (КотлOFF support)

1. @kotloffgazbot — КотлOFF admin (основной бот)

Функционал:

Принимает заявки с сайта через HTTP-запросы (Flask endpoint /send_application)

### Примеры использования API
Здесь очень простая логика, заходим на сайт, и требуем ссылку или ID для доступа
``` TypeScript
export class AppService {
  private readonly FIREBASE_URL = 'Ваш ID';
  private readonly GOOGLE_SHEETS_URL = 'Ваш ID';
  private readonly BOT_TOKEN = 'Ваш ID';

  async handleRequest(data: any): Promise<any> {
    const { name, phone, comment } = data;

    if (!name || !phone) {
      return { success: false, message: 'Заполните имя и телефон' };
    }

    try {
      console.log('=== НАЧАЛО ОБРАБОТКИ ===');
      
      const applicationId = `app_${Date.now()}`;
      console.log('ID заявки:', applicationId);
      
      const firebaseData = {
        id: applicationId,
        name: name.trim(),
        phone: phone.trim(),
        comment: comment || '',
        timestamp: new Date().toISOString(),
        source: 'website',
        status: 'new',
      };
      
      console.log('Данные для Firebase:', firebaseData);
      
      console.log('Сохранение в Firebase...');
      await this.saveToFirebase(firebaseData);
      console.log('Firebase сохранено');
      
      console.log('Отправка в Google Sheets...');
      await this.sendToGoogleSheets(name, phone, comment);
      console.log('Google Sheets отправлено');
      
      console.log('Отправка в Telegram...');
      await this.sendToTelegram(name, phone, comment, applicationId);
      console.log('Telegram отправлено');

      return {
        success: true,
        message: 'Заявка успешно отправлена',
        applicationId: applicationId,
      };
    } catch (error) {
      console.error('=== ОШИБКА ОБРАБОТКИ ===');
      console.error('Сообщение:', error.message);
      return {
        success: false,
        message: 'Ошибка при отправке заявки',
      };
    }
  }

  private async saveToFirebase(data: any): Promise<void> {
    const url = `${this.FIREBASE_URL}/applications/${data.id}.json`;
    console.log('Firebase URL:', url);
    
    const response = await axios.put(url, data);
    console.log('Firebase ответ:', response.status);
  }

  private async sendToGoogleSheets(name: string, phone: string, comment: string): Promise<void> {
    const params = new URLSearchParams();
    params.append('name', name);
    params.append('phone', phone);
    params.append('comment', comment || '');

    const response = await axios.post(
      this.GOOGLE_SHEETS_URL,
      params.toString(),
      {
        headers: {
          'Content-Type': 'application/x-www-form-urlencoded',
        },
      }
    );
    
    console.log('Google Sheets ответ:', response.data);
  }
```

## Хостинг

 ### 1. https://railway.com
 Для хостинга бэкенда, фронтенда и бота мы использовали бесплатную подписку на 30 дней на сайте railway.com

Для проверки работоспособности и подключения мы созадвали уникальные домены для каждого хоста, например по ссылке https://tg-bot-production-9b5a.up.railway.app/health можно проверить
работоспособность хостинга телеграмм бота, а именно что сервис railway отправляет и принимает запросы от бота

Работает сам сервис крайне просто: необходимо загрузить готовый проект либо сразу на сайт, либо (что намного удобнее) в репозиторий на гитхабе, далее, если выбрали гитхаб (если выбрали загрузку через
сайт, то ничего делать не надо) вы выбираете ваш репозиторий, крайне важно, чтобы необходимые для хоста файлы находились в корневой папке, чтобы railway мог сразу их прочитать, ведь он не способен
открывать папки внутри репозитория, после этого они загружаются и хостятся.

Так же необходимо создать в корне репозитория файл под названием Dockerfile (он не должен быть никакого формата - ни .txt и .jsx, просто Dockerfile), именно его в первую очередь считывает railway,
, по сути - это инструкция по сборке для сайта, а так же необходимо создать файл requirements.txt, который будет содержать необходимые библиотеки

После создания и загрузки всех файлов, при выборе хоста (квадратное окошко с названием вашего репозитория), необходимо создать во вкладке Settings --> Networking --> Public Networking отдельный домен
для того, чтобы потом соединить ваш хост с бэкендом (заменить ссылку в файле app.service.ts). https://ВАШ_ДОМЕН так будет выглядеть ваша сылка на домен (естественно вместо ВАШ_ДОМЕН вы вставляете
ваш домен :)), ссылка которую вы должны будете вставить, будет выглядеть вот так https://ВАШ_ДОМЕН/send_application. 

После выполнения всех описанных шагов, вы сможете захостить свой проект, удачи🔥
